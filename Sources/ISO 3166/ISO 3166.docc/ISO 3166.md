# ``ISO_3166``

@Metadata {
    @DisplayName("ISO 3166")
    @TitleHeading("Swift Standards")
}

Represent ISO 3166-1 alphabetic and numeric country codes as validated Swift
values, with complete generated registry accessors and conversions.

The generated declarations are the package's canonical registry snapshot.
When the authoritative registry changes, update all three code families, their
`CaseIterable` collections, and every conversion mapping together.
